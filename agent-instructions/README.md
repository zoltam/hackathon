# Shared agent skills

Active project skills live in [`.agents/skills/`](../.agents/skills/) so Codex can discover them when opened in this repository:

- [Hackathon orchestra](../.agents/skills/hackathon-orchestra/SKILL.md): coordinates delegated work when requested. Moved from this folder without changing its contents.
- [Ponytail](../.agents/skills/ponytail/SKILL.md): guidance for small, complete code changes.

Teammates receive these files when they pull the repository. Open Codex in the repository; use a new turn or session if an existing session has not refreshed its skill list. Discovery makes a skill available; its description or an explicit request determines when it is used.

Ponytail is an unchanged copy of `skills/ponytail/SKILL.md` from [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail/tree/96608e078b2d5ea607c5c3b8b5a54d1c1fba6846), pinned to commit `96608e078b2d5ea607c5c3b8b5a54d1c1fba6846`. Its MIT license is included alongside it. This is the instruction skill only; plugin hooks and executable integrations are not installed.
